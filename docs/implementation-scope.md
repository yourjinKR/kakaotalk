# 설치 리소스와 v0.1 구현 범위

작성일: 2026-10-22. 원본 근거는 [reverse-engineering.md](reverse-engineering.md)와 그 문서가 참조하는 Evidence에 있습니다. 아래 구현은 복구한 원본 코드가 아니라 독립적으로 작성한 서비스입니다.

| 기능 | v0.1 상태 | 범위와 차이 |
| --- | --- | --- |
| 친구 찾기·추가 | 구현 | 서비스 내부 ID/이름 검색. 전화번호, 카카오 ID 조회, 연락처 동기화 제외 |
| 프로필·즐겨찾기·별명 | 구현 | 별명/즐겨찾기는 나에게만 적용. 아바타는 이니셜/색상 |
| 숨김·차단·삭제 | 구현 | 숨김은 목록에서 제외하되 수신 유지. 삭제 후 기존 대화 유지. 차단은 양쪽 1:1 전송 제한 |
| 차단 해제 | 구현 | 바로 일반 친구 상태로 복원. 원본의 해제 후 추가 선택은 후속 범위 |
| 나와의 채팅 | 구현 | 개인 메모용 텍스트 대화 |
| 1:1·그룹 대화 | 구현 | 실제 계정 간 SSE 수신과 SQLite 영속 저장 |
| 읽음·안 읽은 수 | 구현 | 사용자별 읽은 메시지 위치로 계산. 실제 보이는 대화만 읽음 처리 |
| 입력 중 표시 | 구현 | 임시 이벤트, 일정 시간 뒤 표시 해제 |
| 채팅 검색·정렬·고정 | 구현 | 방/참여자 검색, 최신/안 읽은 순, 상단 고정. 원본의 고정 최대 10개 제한은 미적용 |
| 알림 끄기 | 구현 | 해당 방의 앱 내부 수신 알림 억제. Windows 시스템 알림은 제외 |
| 대화 내용 검색 | 부분 구현 | 이미 가져온 최근 200개에서 부분 문자열 검색. 전체 이력 검색·페이지 로딩 제외 |
| 방 이름·대화상대 | 부분 구현 | 참가자 표시와 그룹 이름 수정. 그룹 이름은 전원에게 공유되며 개인별 방 이름/사진은 제외 |
| 전송 실패·재시도 | 부분 구현 | 실패 안내와 초안 유지. 동일 내용 재시도에 중복 방지 키 재사용. 말풍선별 전송 대기/실패 목록 제외 |
| 방 나가기 | 구현 | 상세 정책은 서버 README. 1:1 상대 식별을 보존하며 나간 사용자의 이전 이력을 감춤 |
| 답장·메시지 삭제 | 후속 | 원문 연결과 나에게만/모두에게 삭제 범위를 별도 설계 예정 |
| 파일·사진·리액션·친구 메모 | 후속 | 이번 버전은 텍스트 대화와 친구 상태 관리에 집중 |

노랑 강조색 `#FEE500`은 설치 리소스에 관찰된 값입니다. 화면의 칼럼 배치, 간격, 반응형 처리, 연한 채팅 배경은 독립 디자인 선택입니다. 원본 레이아웃 파일은 불투명한 바이트여서 실제 화면 치수나 이벤트 연결은 확인되지 않았습니다.

REA는 PE 리소스와 설치본 식별에 사용했습니다. Ghidra/IDA가 설정되지 않은 환경이라 네이티브 함수, 서버 프로토콜, 암호화 구조, 실제 실행 흐름을 복구했다고 주장하지 않습니다. 증거 레코드의 complete는 지정한 PE 리소스 트리 범위에만 해당합니다.
