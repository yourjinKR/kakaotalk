## 관찰에서 도출한 흐름과 한계

**확인됨:** 친구 탭→검색창 열기/닫기, 친구 추가→연락처/ID 탭 전환/취소, 친구 행→관리 메뉴, 채팅 탭→새채팅→일반채팅→단일/복수 참여자 선택→취소.

**추론:** 단일 참여자 선택은 1:1, 복수 선택은 그룹 시작 경로로 연결될 가능성이 높다. 배포 문자열의 1:1/그룹 정의와 함께 최소 구현의 근거로 사용한다. 실제 확인 후 결과까지 관찰한 것은 아니다.

**추가 확인 필요:** 친구 검색의 일치 알고리즘, 추가 완료/중복/차단 오류, 숨김·삭제·차단의 확정 결과, 같은 상대의 방 재사용, 실제 송신·재시도, 수신 지연, 메시지별 읽음 숫자와 정확한 읽음 트리거. 상대방이 있는 검증은 명시된 테스트 계정/대상과 함께 진행한다.

제품 디자인, 색상, 아이콘, 검색 구현, 메시지 순번·읽음 커서, 저장 구조는 관찰한 UI를 복제한 것이 아닌 독립 설계다.
