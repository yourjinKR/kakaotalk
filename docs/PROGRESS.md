# 카톡 개발 진행 기록

최종 갱신: 2026-10-22 (Asia/Seoul)

## 현재 결과

친구 관리와 텍스트 채팅 중심의 **실행 가능한 로컬 v0.1**이 완성되었다. 단순 UI 목업이 아니라 서로 다른 계정이 실시간 대화하고 서버 재시작 후에도 기록을 유지하는 독립 서비스다. React 화면은 브라우저와 Electron PC 앱에서 공용으로 사용한다.

사용자 요청: 설치된 카카오톡을 역공학하여 친구·채팅에 집중한 나만의 서비스를 만든다. 이름은 `카톡`으로 해석했다. 사용량 제한으로 여러 요청에 걸쳐 이어가므로 중복 분석을 줄이고 이 기록을 먼저 읽는다.

## 완료한 기능

- 가상 예시 계정 4개, 자체 회원가입·로그인·로그아웃, 비밀번호 scrypt 해시와 HttpOnly 세션.
- 친구 ID/이름 검색·추가, 별명, 즐겨찾기, 숨김·복원, 차단·해제, 삭제, 내 이름·상태메시지.
- 1:1·그룹·나와의 채팅, SQLite 저장, SSE 실시간 수신, 미읽음 수·읽음 갱신, 입력 중 표시.
- 이모지, 계정/방별 초안, Enter/Shift+Enter와 한국어 IME 처리, 최대 4,000자, 전송 실패 시 초안 유지와 중복 방지 키.
- 방/참여자 검색, 최신/미읽음 정렬, 상단 고정, 앱 내부 수신 알림과 방별 알림 끄기, 최근 200개 대화 검색.
- 그룹 이름 수정, 참여자 정보, 방 나가기. 1:1 나가기 후 상대 식별 유지·신규 메시지로 복원·이전 기록 비노출.
- 모바일 단일 패널, 모달 키보드 포커스 관리, 빈 상태, 오류 안내.
- Electron 전용 로컬 서버 자동 시작·종료, 격리된 렌더러, 재실행 시 데이터 유지.

검증 환경: Node 22.23.2, Electron 45.0.0. 정확한 JS 패키지는 `package-lock.json`에 고정. Electron 45는 `npm install`과 실행 파일 다운로드가 분리되어 있으므로 `desktop:install`을 자동 선행하도록 구성했다. 네트워크/loopback/GUI 실행은 샌드박스에서 제한되어 필요한 명령만 승인된 실행으로 검증했다. 미해결 자동 승인 거절은 없다.

## 역공학 근거와 한계

설치본 `C:\Program Files (x86)\Kakao\KakaoTalk\KakaoTalk.exe`, 버전 26.9.0.5337, x86 PE.

SHA-256: `23d0025988d3dd413801823657c5ac00e69945221d973aef7314f220142ab6a5`

REA로 PE 리소스 분석 성공 후 Evidence를 내보내고 세션을 닫았다. 정식 XML 파싱으로 한국어 UI 문자열 84개와 색상/상태 선언을 선별했다. Ghidra/IDA 미설정, 불투명 레이아웃 파일 때문에 원본 함수 디컴파일·정확한 화면 치수·프로토콜은 미확인이다. 개인 대화 DB·자격증명·친구 목록은 읽지 않았다.

설치 리소스와 독립 구현의 차이는 [implementation-scope.md](implementation-scope.md)에 적었다. 차단의 양방향 정책, 공유 그룹 이름, 고정 한도 미적용 등은 원본 그대로 복원한 동작이 아니다.

## 다음 개발 순서

1. 메시지 이력 커서 페이지 로딩과 전체 대화 검색: 현재 화면은 최근 200개만 로드한다.
2. 답장·메시지 삭제: 원문 연결, 나에게만/모두에게 삭제 범위, 읽음과 삭제의 일관성부터 설계한다.
3. 그룹 초대/퇴장 알림·권한, 개인별 방 이름, 친구 메모, 고정 최대 10개.
4. 파일/사진, OS 알림, 프로필 사진 등 텍스트 채팅 이후의 기능.
5. 실제 여러 PC 간 서비스가 필요할 때 서버 배포·HTTPS·운영 계정 정책·접속 제한·복구를 설계한다. 현재는 loopback 실행용이다.
6. Windows 설치 프로그램·자동 업데이트는 별도 배포 단계다. 현재 `npm run desktop`으로 PC 앱을 실행할 수 있다.

원본 네이티브 코드를 더 분석해야 하는 구체적인 질문이 생겼을 때만 Ghidra/IDA 가용 경로를 확인한다. 등록이 이미 정상인 REA MCP를 재설치하지 않는다.

## 실행·재개 시 주의

루트 [README](../README.md)에 실행 명령·가상 계정·데이터 경로가 있다. `.data`와 실제 Electron 사용자 데이터는 보존한다. 실시간 테스트는 일반 탭 2개 대신 서로 다른 브라우저 컨텍스트/시크릿 창을 사용한다. 테스트는 `test-results` 내 독립 DB를 사용한다.

브라우저 미리보기는 `npm start`로 3001에서 제공한다. Vite 개발 모드는 5173/3001, UI 테스트는 3101, PC 앱은 일반 실행에서 임의 포트를 사용한다. 앞선 실행이 중단되어 포트가 비어 있으면 서버만 다시 시작하면 된다. 빌드된 화면을 수정했다면 `npm run build` 후 새로고침한다.
