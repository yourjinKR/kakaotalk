# 카톡

친구 관리와 일반채팅에 집중하는 독립 메신저 프로젝트입니다. 설치된 카카오톡 Windows 26.9.0.5337의 배포 파일과 실제 화면을 관찰하고, 원본 코드·이미지·아이콘을 복사하지 않고 구현합니다.

현재는 **PC 브라우저에서 실행하는 localhost 개발 프로토타입**입니다. 합성 사용자 네 명 사이에 로컬 서버를 통한 실제 메시지 송수신이 가능합니다. 인터넷 서비스, 실제 로그인, 다른 PC 연결, Windows 설치 패키지는 아직 제공하지 않습니다.

## 실행

Node.js 22 이상이 필요합니다. 외부 패키지가 없어 `npm install`은 필요하지 않습니다.

```powershell
npm start
```

[카톡 열기](http://127.0.0.1:4173) · [김하나 세션 열기](http://127.0.0.1:4173/?user=hana)

상단의 사용자 선택 또는 **다른 사용자 열기**로 두 창을 열어 대화를 주고받을 수 있습니다. `me`, `hana`, `jun`, `sora`는 합성 테스트 계정이며 사용자 전환은 인증 기능이 아닙니다. 최초 실행 시 안내 메시지 하나가 생성되며 자동 답장은 없습니다.

```powershell
npm test
```

기본 저장 파일은 `data/messenger.json`입니다. 서버를 다시 실행해도 친구·채팅·읽음 상태가 유지됩니다. `PORT`, `KATOK_DATA_FILE` 환경 변수로 포트와 저장 경로를 지정할 수 있습니다. 하나의 저장 파일은 서버 프로세스 하나에서만 사용하세요. 손상된 파일은 덮어쓰지 않고 시작 오류를 표시합니다. 저장 데이터와 테스트 임시 파일은 Git에서 제외합니다.

## 현재 기능

- 친구 목록·이름/ID 검색, ID로 친구 추가, 중복·미존재 오류
- 친구 숨김·복귀와 프로필에서 1:1 대화 시작
- 채팅방 목록·참여자 검색, 1:1 방 재사용, 새 그룹 생성·참여자 보기
- 텍스트 송수신·줄바꿈·실패 시 재시도, SSE 갱신, JSON 저장
- 채팅방의 안 읽은 메시지 수, 발신 메시지를 안 읽은 참여자 수

숨김은 메시지 수신을 막지 않습니다. 차단·삭제·연락처 추가·그룹 초대/탈퇴는 후속 구현입니다. 검색·읽음·저장·방 재사용의 구체적인 규칙은 [독립 설계](docs/ARCHITECTURE.md)에 기록했습니다.
